# Licencia y atribución de datos

Los archivos analíticos de `datos/` son una transformación de bases de Datos Abiertos del Ministerio de Educación de Chile, Centro de Estudios/SIES.

Fuente: <https://centroestudios.mineduc.cl/datos-abiertos/>.

La reutilización de estos datos derivados queda sujeta a las condiciones publicadas para las bases de origen, incluida su atribución y las restricciones de uso no comercial cuando correspondan. Este repositorio no redistribuye los archivos oficiales completos.

El código fuente del repositorio se distribuye bajo la licencia MIT incluida en `LICENSE`.
